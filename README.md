# SeedChecker

A Fabric client mod that scans the biomes around spawn (0, 100, 0) and groups anarchy sub-servers by their world generation, so you can tell which physical world you've been routed to.

## Requirements
- Minecraft 1.21.8
- Fabric Loader >= 0.16.0, Fabric API
- Java 21+

## Build
```bash
cd overworld
./gradlew build
```
The built jar lands in `overworld/build/libs/`. Drop it into your `mods/` folder.
